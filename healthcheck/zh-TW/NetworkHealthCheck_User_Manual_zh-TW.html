1 這個工具是什麼

網路健檢工具站在這台電腦的角度看網路，把看到的記下來：哪些網卡已連線、它們的位址是什麼、路由器（預設閘道）有沒有回應、名稱查得到查不到、幾個已知的服務連不連得上、連線有沒有掉封包或重傳資料。結果是一份報告，最上面是一行整體結果，再來是一段「要告訴 IT 的話」。

它不改任何設定。 工具只讀取網路資訊並執行連線測試：幾次 Ping、一次名稱查詢、一次 TCP 連線、一次 HTTPS 請求。它不會修改 IP、DNS、路由、防火牆、Proxy 或網卡設定，也不安裝任何東西。一般情況下不需要系統管理員權限。

它不會上傳任何東西。 報告留在這台電腦上，除非你自己把它送出去。測試送出的是往測試目標的流量（第 9 節列出出廠的目標），經由這台電腦自己的 DNS 伺服器、Proxy 與路由。

要多久。 網路正常時大約十秒。有東西不回應時會久一些，最多一分鐘上下，因為每項測試都會等到時限才放棄。

2 開始之前

  1. 把 ZIP 存到電腦上。 IT 給你的檔案，或是從他們給的連結下載的檔案，先存檔。不要直接從瀏覽器的下載列開啟。
  2. 可以的話先解除封鎖。 在 ZIP 上按右鍵 → 內容 → 勾選最下方的 解除封鎖 → 確定。Windows 會標記從網際網路下載的檔案，執行前先問一次安全性問題；解壓縮前先解除封鎖，就不會再問。沒有這個核取方塊，表示沒有東西需要解除，直接往下做。
  3. 整包解壓縮。 在 ZIP 上按右鍵 → 解壓縮全部… → 解壓縮（不同 Windows 版本的字樣略有不同）。Windows 會建議一個和 ZIP 同名的資料夾，用它就可以。放在本機任何位置都行，例如桌面或文件。
  4. 資料夾要整包保留。 啟動器需要程式和設定檔在旁邊。要搬或複製就搬整個資料夾，不要只拿單一檔案。
不要在 ZIP 視窗裡直接執行。 對 ZIP 按兩下會把內容顯示得像資料夾，但它不是資料夾：Windows 只會把你按的那一個檔案解到暫存位置。啟動器在旁邊找不到程式，就會停下來說「找不到程式檔 NetworkHealthCheck.ps1」。先解壓縮。

3 執行檢測

  1. 打開解壓縮出來的資料夾，按兩下 Start-Traditional-Chinese.cmd。（進入 zh-TW 資料夾按兩下 Start-NetworkCheck.cmd 也是同一件事。）
  2. 若 Windows 顯示 開啟檔案 - 安全性警告，選 執行。那是第 2 節說的下載標記，工具本身沒有差別。
  3. 先出現一個黑色文字視窗，檢測結束前它會一直留在背景。不用理它。
  4. 接著 網路健檢工具 1.2.4 視窗打開，一秒內自己開始。你會看到：
    畫面上意思
    結果：檢測進行中正在檢測
    進度列和它上方那一行目前進行的步驟，接近結束時會有幾秒顯示 TCP 重傳取樣中，尚餘約 N 秒
    記錄區每個步驟、每個發現各一行，依發生順序排列
    按鈕檢測中 開始檢測 是灰的；開啟報告、開啟報告資料夾、開啟 JSON 要等做完才會亮起；在那之前 關閉 沒有作用
  5. 等它做完。 進度列上方那一行變成 檢測完成，結果那一行用顏色顯示整體結果，記錄區最後一行寫出報告位置：報告已產生：…。按鈕下方也會顯示同一個路徑：報告：…，開始檢測 則變成 重新檢測。
  6. 按 開啟報告。報告會在瀏覽器裡打開。它是這台電腦上的檔案，不是網際網路上的網頁。

在問題發生的時候跑。 工具量的是一台電腦的一個瞬間。問題如果時好時壞，一切正常時跑的那一次證明不了什麼，問題發生時跑的那一次才是 IT 需要的證據。跑的時候照平常的方式繼續使用網路：有幾秒鐘它在量這台電腦自己的流量，什麼都不做的電腦就沒有東西可量。

再跑一次。 重新檢測 會在同一個視窗裡開始新的一輪。每一輪都寫出一組新的報告檔，檔名帶自己的時間，先前的報告不會被覆蓋。一份好的時候、一份壞的時候，兩份報告對 IT 的價值高於任何一份單獨的。

4 看懂結果

整體結果

視窗裡的結果那一行，以及報告最上方的彩色方塊，會顯示四種整體結果之一：

整體結果工具的說明對你的意思
整體正常本次可執行的必要檢查均通過。這一刻檢測看得到的東西都正常。問題如果還在，多半在檢測碰不到的地方，例如應用程式或伺服器，或者它時好時壞：問題發生時再跑一次。
需要注意沒有必要項目失敗，但有警告或品質異常。有連上線，但有些地方不對勁：封包遺失、延遲偏高、重傳、網卡錯誤，或其他警告。把報告送出。
偵測到異常至少一項必要檢查未通過。檢測要求的某個項目壞了。報告會寫出是哪一項、看到了什麼。把報告送出。
檢測未完整部分檢查因權限、系統元件或執行錯誤而無法完成。工具在這台電腦上有東西量不到。這不是網路故障的證明，也不是你做錯了什麼。把報告原樣送出。

要告訴 IT 的話

整體結果下面有一段「要告訴 IT 的話」：一個標題加兩到四行。先讀這一段，它是工具自己對問題在哪裡的判讀，是寫給你看的；最後一行永遠會提醒你該送哪個檔、裡面有什麼。

標題內容
全部通過本次執行的所有檢查都通過。若問題仍然存在，可能在應用程式或伺服器端，或是時好時壞；問題發生時再跑一次。
本機連線問題找不到可用的網卡或預設閘道。問題在這台電腦或它的連線：網路線、Wi-Fi 連線、網卡停用或 DHCP 沒有回應。用同一個網路上的另一台裝置測試，確認是否只有這台電腦有問題。
閘道沒有回應已設定預設閘道，但閘道不回應 Ping。問題在這台電腦和路由器之間：連線、Wi-Fi、交換器或路由器本身。確認連線燈號或 Wi-Fi 訊號，以及其他裝置能否連到路由器。
閘道正常，網際網路不通路由器有回應，但往外的連線失敗。問題在路由器或更外層：WAN 連線、ISP 或上游防火牆。查看路由器的 WAN 狀態，以及其他裝置是否同樣無法上網。
名稱解析失敗用 IP 直接連線正常，但主機名稱無法解析。問題在 DNS：設定的 DNS 伺服器、過濾服務或名稱本身。把報告中的 DNS 伺服器和公司預期設定比對。
連線正常但品質不佳連線可用，但封包遺失、延遲、重傳或網卡錯誤超過門檻。常見原因：Wi-Fi 訊號弱、線路壅塞、網路線或連接埠故障。問題發生時再跑一次並比較數字。
有必要檢查未通過至少一項必要檢查未通過，請看下方失敗的項目。把報告原樣交給 IT。
部分檢查無法執行沒有發現故障，但部分步驟在這台電腦上無法完成。把報告原樣交給 IT，原因記錄在詳細資料中。
有需要注意的警告沒有必要檢查失敗，但有檢查提出警告，請看標示的項目。把報告原樣交給 IT。

前三種問題標題點名的是你自己就能先看的事：網路線、Wi-Fi 訊號、同一個網路上的另一台裝置是不是也一樣。其餘的交給 IT。

報告的其他部分

  • 電腦與執行資訊：電腦名稱、使用者、作業系統、工具版本，以及設定檔和報告存放的位置。
  • 檢測結果：每項檢查一列：時間、分類、檢查項目、結果標籤、說明。說明下方的 顯示詳細資料 會展開背後的量測值（每一次 Ping 的回覆、網卡的位址、IT 可以自己重做一次的指令）。表格上方的 全部展開／全部收合 一次打開或關上所有項目。標籤的意思：
    標籤意思
    正常檢查有執行，結果符合規則
    需注意檢查有執行，結果沒有違反規則，但值得留意：遺失或延遲超過門檻、計數器達到警告值、關於這次執行本身的提示
    異常檢查有執行，但結果不符合規則
    無法檢查這個步驟沒有完成：權限、缺少系統元件、公司政策或執行錯誤。不等同於網路本身一定異常
    資訊只是記錄、沒有判定的事實：電腦名稱、虛擬網卡、沒有回應的選用測試目標、IT 尚未在設定檔填入公司標準的提示
  • IT 診斷資料：收合在最下面：Wi-Fi 無線細節、路由、閘道的硬體位址、Proxy 設定、traceroute 的前幾跳、網卡驅動程式。這些列是給 IT 看的，永遠不影響整體結果。不打開也沒關係。
  • 整體結果下方的六個數字（正常、需注意、異常、無法檢查、資訊、合計）是檢測結果表格的列數統計。

和 HTML 一起寫出的 TXT 與 JSON 檔記的是同樣的發現：文字檔給沒有瀏覽器的場合讀，JSON 檔給 IT 的工具用。視窗裡的 開啟 JSON 會用記事本打開它。

5 把報告交給 IT

送哪個檔。 開啟報告 打開的那一個，通常是 .html。IT 若也要 JSON，開啟 JSON 會顯示它，開啟報告資料夾 則直接帶你到三個檔案所在的位置。如果 HTML 寫不出來（很少見，視窗會說），開啟報告會改開文字檔或 JSON 檔，那也是報告：送那一個。

檔案在哪裡。 按 開啟報告資料夾。預設報告放在程式旁邊的 Reports 資料夾，也就是 zh-TW\Reports，每一輪寫出三個檔案：

NetworkHealthCheck_<日期>_<時間>_<電腦名稱>.html
NetworkHealthCheck_<日期>_<時間>_<電腦名稱>.txt
NetworkHealthCheck_<日期>_<時間>_<電腦名稱>.json

IT 可能設定了別的資料夾。若原本的資料夾無法寫入，工具會改存到 Windows 暫存資料夾底下（%TEMP%\NetworkHealthCheck\Reports），並在視窗和報告裡說明。按鈕下方顯示的路徑永遠是實際使用的那一個。

原樣送出。 不要編輯報告。把檔案附在工單或電子郵件裡，或複製到 IT 指定的地方。舊報告是一般檔案，不需要時可以刪除。

報告裡有什麼。 電腦名稱、你的使用者名稱、各網卡連同 MAC 與 IP 位址、閘道與 DNS 伺服器、Wi-Fi 網路名稱（SSID）與基地台的硬體位址（BSSID）、測試連過的位址，以及工具遇到的錯誤內容。請依公司對這類資訊的規定處理這個檔案。工具本身絕不會把它上傳到任何地方。

6 有東西不對時

你看到的意思怎麼做
按兩下啟動器時出現 開啟檔案 - 安全性警告檔案帶著 Windows 對網際網路下載檔的標記選 執行。不想再被問，就在解壓縮前先解除封鎖 ZIP（第 2 節）
黑色視窗顯示 錯誤：找不到程式檔 NetworkHealthCheck.ps1，並列出錯誤報告 LauncherError.txt只有一個檔案被解出來，通常是在 ZIP 視窗裡按了兩下，或者只複製了單一檔案把整個 ZIP 解壓縮到資料夾，從那裡執行啟動器
黑色視窗顯示 錯誤：此電腦找不到 PowerShell程式需要 Windows PowerShell，它是 Windows 的一部分請 IT 檢查這台電腦，或改在另一台電腦執行檢測
黑色視窗說檢測程式結束代碼為 3，程式旁邊（或 Windows 暫存資料夾）多了一個 NetworkHealthCheck_ENVIRONMENT_<時間>.txt公司的安全政策限制了 PowerShell 在這台電腦上能做的事。工具在任何檢測開始前就停下，把這個檔案寫給 IT。沒有讀取也沒有變更任何東西你這邊沒有什麼要修的。把這個環境檔連同你的請求交給 IT：裡面寫了電腦、限制內容和 IT 可以怎麼做
黑色視窗說檢測程式結束代碼為其他數字，PowerShell 或公司安全政策可能阻擋執行Windows PowerShell 拒絕執行程式，並在錯誤上方印出了原因把錯誤上方那幾行連同 LauncherError.txt 一起交給 IT。若寫著檔案未經數位簽署或被原則封鎖，需要 IT 放行程式
黑色視窗列出一個錯誤報告（LauncherError.txt）啟動器把發生的事寫下來了，附一行依原因而定的 建議照建議做，並把檔案連同請求送出。檔案在啟動器旁邊；那個資料夾無法寫入時，會改寫在 Windows 暫存資料夾裡的 NetworkHealthCheck_LauncherError.txt，視窗會印出路徑
沒有視窗出現，檢測改在黑色視窗裡以文字進行，做完黑色視窗就關掉圖形介面在這台電腦上無法啟動，工具自己切換成文字模式。同樣的檢測都跑了，報告寫到平常的資料夾，報告裡有一列警告說明這件事打開 Reports 資料夾（第 5 節），照常送出最新的報告。想讓文字留在畫面上，改用 zh-TW 資料夾裡的 Start-NetworkCheck-Console.cmd：它以文字模式跑同樣的檢測，結束時會暫停，報告路徑就印在上方
報告裡有一列 啟動提示 警告：「目前是從壓縮檔內執行…」你是在 ZIP 視窗裡執行工具的。報告寫到了視窗關閉就消失的暫存位置整包解壓縮（第 2 節）再跑一次
一列 啟動提示 警告：「原始報告目錄無法寫入，已改存到：…」平常的 Reports 資料夾寫不進去，報告改存到那一列寫的資料夾不用修什麼。開啟報告資料夾 會開到正確的位置
訊息方塊 報告產生失敗，列出緊急錯誤報告 NetworkHealthCheck_FATAL_<時間>.txt檢測跑了，但一個報告檔都寫不出來把 FATAL 檔交給 IT，裡面有失敗前檢測找到的一切
訊息方塊說 3 種報告格式中有 N 種無法寫入部分報告檔存不了，存成功的那一個寫在訊息裡送那一個。開啟報告 打開的就是它
訊息方塊 檢測無法完成，列出一個錯誤報告工具遇到無法恢復的錯誤，把它知道的寫下來了送它列出的那個檔案
整體結果是 檢測未完整這台電腦上有東西量不到把報告原樣送出，原因在標示無法檢查的那幾列
黑色視窗一閃就關掉，什麼都沒發生PowerShell 在工具能開口之前就被擋下了，通常是公司政策告訴 IT 你看到什麼。來得及的話拍一張視窗的照片，會有幫助

啟動提示那一列是警告，所以光是它就會讓整體結果變成 需要注意，網路本身可能還是好的。讀那一列的內容。

7 IT 請你用 IT 入口的時候

zh-TW 資料夾裡的 Start-NetworkCheck-IT.cmd 開的是同一支工具，上方多了一個 執行選項（IT） 面板，而且不會自己開始：進度列上方那一行寫著 就緒，調整選項後按「開始檢測」。IT 可能請你在 額外 Ping 填一個位址、在 額外 TCP（host:port） 填主機和連接埠、在 額外 DNS 填名稱、在 額外 URL 填網址，或改一下 Ping 次數、取樣秒數，然後按 開始檢測。之後打開報告時，每個項目的詳細資料都已經展開。這裡填的東西只對那一次執行有效，永遠不會改到設定檔。還原設定檔 會把面板放回設定檔的值。

9 常見的問題

它會改我電腦上的東西嗎？ 不會。它讀取網路資訊並執行連線測試，不碰 IP、DNS、路由、防火牆、Proxy 或網卡設定，也不安裝任何東西。

需要系統管理員嗎？ 一般不需要。工具若因為權限不足而讀不到某樣東西，那一列會標示無法檢查，檢測繼續進行。

報告會被送到哪裡嗎？ 不會。它寫在這台電腦的資料夾裡，除非你送出，否則哪裡都不去。

它會連到哪些位址？ 以出廠設定來說：你自己的預設閘道、公網位址 1.1.1.1（一次 Ping、一次連接埠 443 的連線，以及 traceroute 往它的前三跳）、https://www.microsoft.com/（經 Windows 設定的 Proxy 的一次網頁請求，會跟隨網頁給的轉址），加上經這台電腦 DNS 伺服器的 www.microsoft.com 名稱查詢。IT 可能已換成公司自己的服務，報告的各列會寫出實際連過的目標。

TCP 重傳那一列寫「無法檢查」。 計數器讀不到：權限、政策，或效能計數器壞了。這不代表有重傳，報告自己也這麼說。原樣送出。

有一列說取樣期間沒有足夠的 TCP 流量。 工具量測時電腦很安靜。那一列是資訊，不是故障。問題若是慢，請在使用網路的時候再跑一次：視訊會議中、下載中，或那個會卡的東西正在跑的時候。

我用 VPN。 報告會同時列出實體網卡和 VPN 網卡；VPN 那張通常標示為虛擬，列為資訊。告訴 IT 你跑檢測時 VPN 有沒有連著。

它說整體正常，但我的問題還在。 檢測看到的是這台電腦的一個瞬間。問題發生時再跑一次，記下時間，告訴 IT 你當時在做什麼：哪個應用程式、哪台伺服器、其他人有沒有一樣的狀況。

可以在別台電腦上跑嗎？ 可以，任何 Windows 10 或 Windows 11 的電腦都行。複製整個資料夾。每份報告都會寫出它是在哪台電腦上做的。

可以改用英文版嗎？ 可以：Start-English.cmd，或 en-US 資料夾。同一支工具，介面和報告是英文。IT 兩種語言的報告都看得懂。

舊報告可以刪嗎？ 可以。它們是 Reports 資料夾裡的一般檔案。

NetworkHealthCheck 1.2.4。本手冊描述的是出廠狀態的工具；IT 在設定檔改過的東西（目標、門檻、報告資料夾）會反映在報告的各列和「電腦與執行資訊」一節。
