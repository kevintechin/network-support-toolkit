# NetworkHealthCheck Portable 1.2.8 — Bilingual Package

- English: run `Start-English.cmd` or open the `en-US` folder.
- 繁體中文：執行 `Start-Traditional-Chinese.cmd`，或開啟 `zh-TW` 資料夾。
- User manual / 使用手冊：`en-US\NetworkHealthCheck_User_Manual_en-US.html` (or `.md`) ／ `zh-TW\NetworkHealthCheck_User_Manual_zh-TW.html`（或 `.md`）。
- IT deployment manual / IT 部署手冊：`en-US\NetworkHealthCheck_IT_Deployment_Manual_en-US.html` (or `.md`) ／ `zh-TW\NetworkHealthCheck_IT_Deployment_Manual_zh-TW.html`（或 `.md`）— configuration, deployment, verification, security policy ／ 設定、部署、驗證、安全政策。
- IT entry / IT 入口：`en-US\Start-NetworkCheck-IT.cmd` or `zh-TW\Start-NetworkCheck-IT.cmd` (run-options panel, expanded HTML details).
- Technical documents / 技術文件：`docs` folder。
- Validation record / 驗證記錄：`VALIDATION.md`（validator: `tools/validate_release.py`）。

Extract the complete ZIP before running. 請先完整解壓縮，不要直接在 ZIP 內執行。
